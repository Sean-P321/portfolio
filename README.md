# portfolio
First SDET101 Project

Sean Persicano's personal portfolio, built with plain HTML, CSS, and JavaScript.

## View locally
Download or clone this repository and double-click `index.html`. No installation or build step is required.

## Progress
All five pages (Home, About Me, Projects, Skills, and Contact) share a responsive navigation menu. The Projects page is ready for project content and currently displays a coming-soon message. The Contact page temporarily displays a clearly labeled placeholder email; it must be replaced with an approved contact method before final submission.
